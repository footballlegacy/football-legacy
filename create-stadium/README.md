# Football Legacy — Create Stadium v2

Standalone stadium builder using the Football Legacy navy, cream and orange UI.

This targeted revision changes only the requested stadium preview and stadium controls:

- wider whole-stadium camera framing and larger zoom range
- automatic high pitch view while choosing pitch wear
- separate main seat, secondary seat and exterior stadium colours
- upgraded multi-tier stadium geometry, roofs, concourses, supports, scoreboards, floodlights, exterior walls, goals and nets
- Mega stadium size with an editable capacity up to 200,000
- existing permanent stadium IDs and browser save format retained, with an added exterior colour field

Open `index.html` in a browser. Three.js is loaded from the same CDN approach used by the first standalone build, so an internet connection is needed when opening it.
