# JavaScript Folder

The files are kept separate so each system can be worked on without opening one enormous script.

Begin with:

- `game.js` for central game flow.
- `ui.js` for what appears on screen.
- `data.js` and `club-database.js` for clubs.
- `people.js`, `personal-life.js` and `legacy-systems.js` for the personal and historical side.

A full explanation is in the root `PROJECT-MAP.md`.
