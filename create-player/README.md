# Football Legacy Create Player — Standalone v4

Targeted update to the v3 match-model player creator.

Changes only:
- removed the attribute quality preset controls;
- added a working long-beard accessory around the locked match-engine head;
- team kits now come from the selected club, with player choices for sleeve length, gloves, boots and boot colour;
- replaced the short team dropdown with a searchable league/division picker containing hundreds of Football Legacy clubs and support for saved created clubs.

Open `index.html` in a browser. Three.js is loaded from its existing CDN dependency.
