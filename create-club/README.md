# Football Legacy — Create Club Standalone v1

Open `index.html` in Safari or Chrome.

## Browser storage used

- Created clubs: `footballLegacyCreatedClubsV1`
- Created players: `footballLegacyCreatedPlayersV1`
- Created stadiums: `footballLegacyCreatedStadiumsV1`

The page is standalone and does not modify the management game or match engine files.
